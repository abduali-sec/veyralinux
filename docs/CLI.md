# Veyra CLI

The `veyra` command provides a unified command-line interface for Veyra Linux.

## Usage

    veyra <command>

## Commands

`veyra info` — display Veyra system information.

`veyra settings` — open Veyra Settings.

`veyra center` — open Veyra Center.

`veyra update` — run the Veyra update flow.

`veyra doctor` — run system diagnostics.

`veyra installer` — launch the Veyra installer.

`veyra welcome` — open the Veyra Welcome flow.

`veyra disks` — open disk tools.

`veyra hardware` — display hardware information.

`veyra audio` — display audio information.

`veyra print` — open printing tools.

`veyra power` — manage power profiles.

`veyra firewall` — open firewall controls.

`veyra about` — display Veyra project information.

`veyra help` — display command help.
