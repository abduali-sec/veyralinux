# Frequently Asked Questions

## What is Veyra Linux?

Veyra Linux is a Linux system built around the Veyra ecosystem.

## What is vpm?

`vpm` is the Veyra Package Manager.

## How do I open Veyra Center?

    veyra center

## How do I diagnose the system?

    veyra doctor

## How do I install Veyra?

Boot the Veyra ISO and launch:

    veyra installer
