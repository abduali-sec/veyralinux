# Installing Veyra Linux

## Live Environment

Boot the Veyra Linux ISO from a USB drive or virtual machine.

The Live environment starts the Veyra desktop.

## Veyra Installer

Launch the installer with:

    veyra installer

or:

    veyra-installer

## Easy Install

Easy Install provides a guided installation process with support for BIOS and UEFI systems, GPT partitioning, EFI system partitions, ext4, Btrfs, optional swap, user creation, hostname, timezone, locale, networking, bootloader installation, and Veyra system configuration.

## Advanced Installation

Advanced and Manual installation modes allow manual partition selection and filesystem configuration.

Always verify the selected disk before formatting or installing.

## After Installation

Remove the installation media and reboot.

The installed system should start the Veyra graphical environment.
