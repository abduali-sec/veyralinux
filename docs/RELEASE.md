# Veyra Release Process

## Pre-release

Before a public release:

- run the final preflight
- build the ISO
- verify the checksum
- test Live boot
- test the graphical environment
- test Veyra applications
- test `vpm`
- test the installer
- test an installed system
- review branding
- review documentation

## Release

A release should include:

- version number
- codename
- ISO image
- SHA-256 checksum
- release notes
- Git tag
- GitHub Release
