# Veyra Package Manager

`vpm` is the package manager used by Veyra Linux.

## Synchronize

    vpm sync

## Search

    vpm search firefox

## Install

    sudo vpm install <package>

## Remove

    sudo vpm remove <package>

## Update

    sudo vpm update

## Verify

    vpm verify <package>
